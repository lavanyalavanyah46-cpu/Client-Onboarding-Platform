# Client Onboarding Platform

A front-end web development internship project for client onboarding.

## Features
- Client profile registration
- KYC verification demo
- Document submission
- Insurance policy selection
- Onboarding status tracking
- Dashboard statistics
- Responsive interface

## Run
Open `index.html` in a browser.

This is a demo project. KYC verification and policy selection are simulated and are not connected to real external services.
